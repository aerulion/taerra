# Contributing

Report bugs in the [issue tracker](https://github.com/aerulion/taerra/issues); questions and ideas go to
[Discord](https://discord.taerra.dev). Pull requests are welcome; the [README](README.md) has the build, the formatting
and the commit message format CI checks.

By opening a pull request you license your contribution to the TAERRA project as section 8 of
[`LICENSE.md`](LICENSE.md) describes: you keep the copyright, and TAERRA may publish it under this or any later
license.
