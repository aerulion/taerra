# Contributing

Report bugs and ideas in the [issue tracker](https://github.com/aerulion/taerra/issues/new/choose), through its
forms; questions go to [Discord](https://discord.taerra.dev). Pull requests are welcome; the [README](README.md) has
the build, the formatting and the commit message format CI checks. A pull request that fixes an issue says
`Fixes #12` in its description. Security issues, permission requests and anything else go to
[contact@taerra.dev](mailto:contact@taerra.dev), see [`SECURITY.md`](SECURITY.md).

By opening a pull request you license your contribution to the TAERRA project as section 8 of
[`LICENSE.md`](LICENSE.md) describes: you keep the copyright, and TAERRA may publish it under this or any later
license.
